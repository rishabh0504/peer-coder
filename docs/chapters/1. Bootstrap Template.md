# Chapter 1: Bootstrap Template & Core CLI Architecture

> **Document Version:** 1.0  
> **Status:** Completed  
> **Purpose:** Document the production-ready Node.js CLI bootstrap architecture for `peer-coder`, detailing module resolution, global linking, build pipelines, path alias resolution, and developer workflow tools.

---

## 1. Executive Summary

`peer-coder` is an autonomous AI coding agent CLI runtime. Chapter 1 establishes the foundational **Bootstrap Template** — a modern, zero-overhead TypeScript CLI platform engineered for rapid development, strict type safety, zero runtime module resolution issues, and seamless local global linking (`pnpm run link`).

---

## 2. Core Architecture Specifications

| Area | Choice | Rationale |
| :--- | :--- | :--- |
| **Runtime Environment** | Node.js (>=18.0.0) | Standard cross-platform Node.js runtime |
| **Package Manager** | `pnpm` (10.4.0) | Fast, disk-efficient dependency management with lockfile immutability |
| **Module System** | Pure ESM (`"type": "module"`) | Modern native JavaScript ES Modules (`NodeNext`) |
| **CLI Framework** | `commander` (v13) | Robust option parsing, subcommand routing, and auto-generated help |
| **Interactive Prompts** | `@clack/prompts` | Premium, accessible terminal UI wizard components |
| **Validation & Schema** | `zod` | Type-safe environment variable parsing & runtime input validation |
| **Bundling Engine** | `tsup` (esbuild) | Sub-second ESM executable generation + `.d.ts` bundle generation |
| **Linting & Formatting** | `biome` | Ultra-fast Rust-based linter and formatter |
| **Testing Suite** | `vitest` | Modern unit testing framework natively compatible with ESM & TypeScript |
| **Git Enforcement** | `husky` + `lint-staged` + `commitlint` | Automated pre-commit linting and conventional commit message validation |

## 5. Build & Global Linking Architecture

### Bundling Configuration (`tsup.config.ts`)
`tsup` compiles `src/cli.ts` into a standalone executable bundle at `dist/cli.js` with `#!/usr/bin/env node` prepended:

```typescript
import { defineConfig } from "tsup";

export default defineConfig({
  entry: {
    cli: "src/cli.ts",
    index: "src/index.ts",
  },
  format: ["esm"],
  target: "node18",
  clean: true,
  dts: true,
  sourcemap: true,
  banner: {
    js: "#!/usr/bin/env node",
  },
});
```

### Global Linking Script (`package.json`)
The template includes a pre-configured `pnpm run link` command that cleans old builds, re-bundles, and globally symlinks the absolute working directory to pnpm's global bin path:

```json
"scripts": {
  "dev": "tsup --watch",
  "build": "tsup",
  "start": "node ./dist/cli.js",
  "typecheck": "tsc --noEmit",
  "lint": "biome check .",
  "lint:fix": "biome check --write .",
  "test": "vitest run",
  "link": "rimraf dist && pnpm build && pnpm link --global $(pwd)",
  "unlink": "pnpm unlink --global peer-coder"
}
```

## 7. CI Pipeline & Caching

The GitHub Actions workflow (`.github/workflows/ci.yml`) is optimized with `actions/cache@v4` to cache the global `pnpm store`, dramatically reducing build times and network bandwidth.
